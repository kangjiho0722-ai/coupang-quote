03 · 자주 묻는 질문

신청 전에 가장 많이 묻는 질문

택배를 직접 발송해도 되나요?

물류 작업은 협력 택배사를 통해 진행합니다. 판매자는 상품 발송 없이 전달받은 운송장번호를 입력해 주세요.

배송 가능 지역은 어디인가요?

전국 배송으로 진행합니다.

실제 리뷰어가 구매하나요?

네. 모집된 실제 리뷰어가 상품별 캠페인 정보를 확인하고 구매를 진행합니다.

로켓 상품도 진행할 수 있나요?

판매자배송 옵션 또는 해당 상품과 매칭된 일반상품 링크를 확인한 뒤 진행 가능 여부를 안내합니다.

리뷰 내용을 직접 준비할 수 있나요?

사전에 말씀해 주시면 직접 준비한 내용을 전달할 수 있도록 진행 방식을 안내합니다.

리뷰는 언제 작성되나요?

배송 완료 후 일반적으로 1~2일 이내 작성됩니다. 일정 요청이 있다면 신청 시 함께 알려주세요.

진행 중 상품가격이 바뀌면 어떻게 되나요?

가격이 인상된 경우 차액 확인과 추가 결제가 필요하며, 확인 전까지 해당 건의 진행이 잠시 중단될 수 있습니다.

검색 순위 상승을 보장하나요?

검색 노출은 상품 경쟁력과 판매 실적, 플랫폼 알고리즘 등 여러 요인의 영향을 받습니다. 특정 순위나 결과를 보장하지 않습니다.

플랫폼 정책상 제한은 없나요?

플랫폼 정책은 변경될 수 있으며 상품 조건에 따라 진행 가능 범위가 달라집니다. 상담 시 현재 조건을 확인한 뒤 가능한 범위를 안내합니다.
